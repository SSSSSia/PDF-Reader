## 3. 文档规则（强制）

1. **单一事实来源层级**：`开发总纲.md` > `重构路线图.md` > 阶段文档 > 其他。下级文档不得与上级冲突；需要冲突时（例如阶段 4 想换渲染路线），**必须先更新上级文档并经用户确认**（走总纲第 9 章决策机制）。
2. **阶段完成必须回填**：每个阶段开发完成后，必须在该阶段文档末尾的「完成记录」章节填写：完成日期、改动文件清单、验收结果、遗留问题。未回填视为阶段未完成。
3. **状态跟踪表只改路线图**：阶段状态（⬜/🚧/✅）只在 `重构路线图.md` 的状态表中维护，各阶段文档内部的任务 checkbox 由开发过程勾选。
4. **代码改契约必须同步文档**：凡改动总纲 4.x 节的数据模型 / 接口，必须同步更新总纲对应表格。
5. 旧文档 `pdf-bilingual-reader-dev-guide.md`（原仓库根）与代码严重不符，已删除（2026-09-08 清理）；如需考古翻 git 历史。

## 4. AI 助手协作协议

与 AI 助手（CodeBuddy 等）协作开发本项目时：

1. **会话开局注入**：按第 2 节"新会话 AI 助手"顺序读取文档，无需重新审计代码。
2. **任务指派格式**：`"执行阶段 N 的任务 T-x"`（对应阶段文档中的任务编号）。
3. **阶段完成后**：AI 必须回填完成记录 + 勾选任务 checkbox + 更新路线图状态表，再汇报。
4. **决策升级**：AI 发现需要偏离阶段文档范围时，停下来询问用户，不得自行扩权（总纲第 7 章约束依然有效）。
5. 项目记忆：AI 工作日志位于 `.workbuddy/memory/`，跨会话延续。
