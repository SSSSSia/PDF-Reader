# 阶段 3：排版与公式（v0.6.0）

> **状态**：🚧 进行中（T2 已提前完成，2026-09-07） ｜ **前置**：阶段 2 完成 ｜ **依据**：瓶颈分析报告 §4
> **目标一句话**：双栏结构化同行对齐（消灭估算漂移）、公式可渲染、紧跟模式对齐 Scholaread 效果。

## 1. 背景与证据

- `position` 全为 0，双栏对齐靠 `minHeight = original.length × 0.8`（BilingualPage.tsx:58）字符估算；中文比英文短，必然错位。
- `useScrollSync` 按滚动百分比同步，两栏高度不同 → 漂移累积。
- 无公式渲染：MarkdownText 无 remark-math/rehype-katex，学术工具硬伤。
- 紧跟模式（InlinePage）已是连续文档流 + 虚线分隔，方向正确，需在阶段 2 跨页合并完成后打磨细节。

## 2. 范围

**做**：双栏结构化对齐重构、KaTeX 接入、紧跟模式精修、图片展示完善。
**不做**：原生渲染/坐标 overlay（阶段 4 决策）、矢量图形提取（阶段 4 一并评估）、术语/翻译质量（阶段 2）。

## 4. 验收标准

1. 双栏模式：任意滚动位置，左右同一 block 严格同行对齐（截图对比，含表格/图片块页面）。
2. 原有"双栏滚动同步"功能退役后无回归：单容器滚动流畅，无两栏各自滚动的错位感。
3. 含 `$E=mc^2$` 的测试 Markdown 渲染出公式（构造一个 block 验证）。
4. 跨页段落：紧跟模式无半段残文重复（复用阶段 2 的验收 PDF）。
5. 图片：Figure 图片原样展示、随排版流位置正确（双模式：Tauri + 浏览器 dev）。
6. 深色模式下全部元素可读。
7. `npx tsc --noEmit` + `npx vite build` 通过；无 Rust 改动。
