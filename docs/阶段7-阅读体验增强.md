# 阶段 7：阅读体验增强——全局缩放与模式重组（v0.9.0）

> **状态**：⬜ 未开始 ｜ **前置**：阶段 6 完成（无强依赖，可并行） ｜ **依据**：用户需求 2026-09-08（Ctrl+滚轮缩放 / 原版默认 70% / 模式重组为【重排版】【原版PDF】两组）
> **目标一句话**：所有阅读模式支持 Ctrl+滚轮随意缩放；模式重组为「重排版」与「原版PDF」两组，原版 PDF 新增左右对照形态（译文与原版对齐）。

---

## 1. 背景与证据

- 用户反馈（2026-09-08）：三种阅读模式均不可缩放；原版 PDF 默认 100% 偏大，期望默认为当前 100% 的 70%。
- 模式现状（`src/stores/uiStore.ts` 三选一）：左右对照（`BilingualPage.tsx`）、紧跟（`InlinePage.tsx`）、原版（`OriginalReader.tsx`，D6=C 可选模式）——用户期望重组为两组：【重排版{左右对照、紧跟模式}】【原版PDF{点击翻译、左右对照}】，其中"原版PDF 左右对照"为新形态：pdfjs 原版渲染 + 译文对照，**格式与原版对齐**。
- 基建就绪：多段 bbox（阶段 5 §5.1，`block.bboxes=[{page,bbox},...]`）已覆盖跨页/断栏/多段拼接，是"原版左右对齐"的坐标基础。

## 2. 范围

**做**：三模式 Ctrl+滚轮缩放 + 缩放持久化、原版默认 70%、模式选择器分两组、新增"原版PDF 左右对照"组件（pdfjs 渲染 + 译文侧栏 + bbox 锚定 + 滚动同步）。
**不做**：对照/紧跟模式的内容改造（仅加缩放）；原版左右对照做逐行级对齐（仅块级）；移动端适配。

## 3. 任务分解

- [ ] **T1 全局缩放（`src/components/ReaderToolbar.tsx`、`BilingualPage.tsx`、`InlinePage.tsx`、`OriginalReader.tsx`、`src/stores/uiStore.ts`）**
  - 容器级 wheel 事件（`ctrlKey` 拦截 preventDefault）：缩放因子 0.7–2.0、步进 0.1，写入 uiStore 并持久化（localStorage `pdf-reader.zoom`）
  - 应用方式：重排版两模式用 CSS 变量（根 font-size 缩放，prose 布局自然跟随）；原版模式调 pdfjs 渲染 scale（已有 canvas 重渲染路径，缩放触发 re-render 当前可视页）
- [ ] **T2 原版默认 70%：`OriginalReader.tsx` 初始 scale 1.0 → 0.7（含 ` OriginalReader` 内部常量与懒渲染视口计算）；已有用户缩放持久化值优先于默认值**
- [ ] **T3 模式选择器分组（`ReaderToolbar.tsx`、`uiStore.ts`）**
  - 模式枚举扩展：`original_click`（现原版）与 `original_bilingual`（新）同属「原版PDF」组；选择器 UI 分「重排版」「原版PDF」两组呈现
- [ ] **T4 原版PDF 左右对照（`src/components/OriginalBilingualPage.tsx` 新组件）**
  - 布局：左 pdfjs 渲染（复用 `OriginalReader` 的懒渲染/取消逻辑，抽公共 hook）+ 右译文面板；块级 bbox 锚定——译文块定位到 `block.bboxes` 首段页坐标，缩放系数联动换算
  - 滚动同步：左栏滚动 → 右栏滚动到对应锚定块；反向可选
  - 回退：bbox 未命中的译文块按文档顺序流入侧栏尾部（不丢失、不悬空）
- [ ] **T5 双栏页缩放适配：重排版双栏 grid 在窄宽度已有降级（阶段3 T4），缩放后复验列宽/换行**

> 任务编号 T1/T2/... 全局内引用格式：`阶段7-Tx`（提交信息与日志用）。

## 4. 验收标准（全部满足才算完成）

1. 左右对照/紧跟/原版点击翻译/原版左右对照四种形态下，Ctrl+滚轮均可在 70%–200% 缩放（步进 10%），重启应用后记住上次缩放值。
2. 原版 PDF 两种形态初始渲染为原 100% 基准的 70%；用户手动缩放后以用户值为准。
3. 模式选择器分「重排版」「原版PDF」两组；原版PDF 组含「点击翻译」「左右对照」两项。
4. 原版左右对照：bbox 命中块的译文与原版对应位置垂直对齐（误差 ≤ 半行高），左栏滚动右栏联动跟随；未命中块译文按顺序流不丢失。
5. 缩放至 70% 与 200% 两端：三模式无布局破碎（文字截断/横向滚动条异常/浮层错位）。
6. pytest 全过、`npx tsc --noEmit` 与 `npx vite build` 通过。

## 5. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 原版左右对照对齐质量受 bbox 覆盖率限制（S1 段级 66–77%，多段修复后提升） | 锚定失败回退顺序流（设计即"匹配不上只是不锚定"，无内容损失）——与 D6 决策口径一致 |
| pdfjs 缩放重渲染性能（连续滚轮触发） | 缩放值防抖 150ms 再触发 re-render；仅重渲染可视页 |
| Ctrl+滚轮与浏览器/WebView2 默认缩放冲突 | 组件 wheel 监听 `preventDefault`；Tauri 窗口禁用内建页面缩放快捷键 |
| 双栏重排版缩放后单栏过宽 | 沿用阶段 3 窄窗口降级断点，缩放等价于有效宽度变化 |
